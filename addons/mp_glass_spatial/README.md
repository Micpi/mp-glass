# MP Glass Spatial

Worker optionnel de génération de plans 3D via Gemini Flash-Lite, piloté depuis Home Assistant. [Installation](DOCS.md).

Avec MP Glass 0.2.1, préférer le [mode Gemini direct](../../docs/GEMINI_QUICKSTART.md) : aucune installation d’add-on, une seule clé API dans l’intégration. Ce worker reste disponible pour la conversion locale des documents.
