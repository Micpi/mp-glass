# Templates chantier — contrat cible

Non livrés dans le premier incrément. Un template futur contient design, catégories, ordre de navigation, priorités et rôles abstraits ; aucun entity_id ni device_id propre à un chantier.

L'import découvrira la nouvelle maison, proposera les correspondances de rôles et affichera les différences avant sauvegarde. Un export actuel de projet n'est pas un template portable automatiquement remappable.
