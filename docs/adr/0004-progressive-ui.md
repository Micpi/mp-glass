# ADR 0004 — valider un parcours complet avant le catalogue

Date : 2026-09-10. Statut : retenu.

Une lumière et son fallback valident découverte, capacités, stratégie, vue et appel service. Le catalogue complet n'est pas annoncé comme livré. Custom view CSS grid avec taille minimale tactile et adaptation container/viewport ; navigation native HA au premier incrément. Une grille responsive ne constitue pas à elle seule les six expériences sémantiques finales.

Les regroupements média, MP Spatial, profils utilisateur et zones HYBRID attendent leurs propres gates. Cette progression conserve les contrats testables et évite les interfaces qui prétendent supporter des commandes inexistantes.
